tylerevans.co / design rules / v0.1

Mesa

Swiss grid, high-desert palette. Organized and clean; the ridge and the rust carry the character.

  1. One accent per view. Rust marks the single thing that matters most.
  2. Condensed = display only. Body text is always normal width.
  3. Mono = metadata only. Dates, paths, nav, labels, code.
  4. Lines, not boxes. Rules divide; no radius, no shadows, no gradients.
  5. Everything sits on the 12-column grid.
